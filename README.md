# Controle de Gastos 💰

Uma aplicação web completa para gerenciamento e controle de finanças pessoais, desenvolvida para ajudar os usuários a acompanharem suas receitas e despesas de forma intuitiva e segura.

## 🚀 Descrição

Este projeto é um sistema de controle de gastos construído do zero, focado em oferecer uma interface amigável e funcionalidades essenciais para a gestão financeira no dia a dia. A aplicação conta com um sistema robusto de autenticação, permitindo que cada usuário tenha acesso privado aos seus próprios dados financeiros.

## ✨ Funcionalidades

- **Gestão de Finanças:** Adição, visualização e controle de entradas (receitas) e saídas (despesas).
- **Autenticação de Usuários:** Sistema de login seguro integrado com Firebase.
- **Recuperação de Senha:** Fluxo completo para redefinição de credenciais via Firebase Authentication.
- **Interface Responsiva:** Layout adaptável para uso em dispositivos móveis e desktops, garantindo uma ótima experiência de uso em qualquer tela.
- **Integração com API:** Comunicação com back-end/APIs para persistência e manipulação dos dados em tempo real.

## 🛠️ Tecnologias Utilizadas

A aplicação foi desenvolvida utilizando as seguintes tecnologias e ferramentas:

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização da interface.
- **JavaScript (ES6+):** Lógica da aplicação, manipulação do DOM e consumo de APIs.
- **Firebase:** Gerenciamento de usuários, autenticação (Login/Cadastro) e fluxo de recuperação de senhas.
- **APIs REST:** Para processamento e persistência das informações.

## ⚙️ Como Executar o Projeto

1. Faça um clone deste repositório:
    ```bash
    git clone https://github.com/joaoamaia1311/Aplica-o-completa-de-controle-de-gastos---HTML-CSS-JS-e-API.git
    ```
2. Navegue até a pasta do projeto:
    ```bash
    cd Aplica-o-completa-de-controle-de-gastos---HTML-CSS-JS-e-API
    ```
3. Configuração do Firebase:
    - Crie um projeto no [Firebase Console](https://console.firebase.google.com/).
    - Ative o método de login por E-mail/Senha no Firebase Authentication.
    - Adicione suas credenciais do Firebase no arquivo JavaScript de configuração (ex: `firebase-config.js` ou diretamente onde as chaves são inicializadas).
4. Abra o arquivo `index.html` (ou a página de login) no seu navegador para iniciar a aplicação, preferencialmente utilizando a extensão Live Server (VS Code) para evitar problemas de CORS.
